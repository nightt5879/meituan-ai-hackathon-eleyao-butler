# 选题想法征集区

这个文件夹用来收集每位队员对**美团 2026 本地生活大赛**选题的初步想法。

## 怎么用

1. **复制** `_template_选题想法.md` 这个模板文件
2. **改名** 为 `你的名字-想法.md`（例如 `lilei-想法.md`；可以放多份，例如 `lilei-想法-01.md`、`lilei-想法-02.md`）
3. **填写** 里面的每一项，不会填的地方写"暂无想法"也行，别空着
4. 通过 GitHub Desktop 的流程 commit + push + 开 PR（详见 `../docs/task2_git_workflow_and_ideas.md`）

## 格式说明

- **推荐 Markdown（.md）**：轻量、版本对比清晰、GitHub 网页能直接预览
- **也接受 Word（.docx）**：如果你更习惯 Word 就用 Word；但缺点是后面队长比对想法时不好 diff
- **不接受**：截图、语音、纯微信消息（要落到仓库里才算数）

## 想法的边界

大赛分两种赛道（详见主办方公告），你的想法可以是：

- **命题赛道（6 选 1）**
  1. 基于 OpenClaw 的本地生活"全天候私人管家"
  2. 复杂指令下的多轮对话评测系统
  3. 美甲 AI 试戴与智能运营
  4. AutoSolver：让 AI Agent 自主求解配送分配问题
  5. 现在就出发：AI 本地路线智能规划
  6. 本地探索：周末闲时活动规划

- **开放赛道**：围绕"本地生活（吃、住、行、游、购、娱）"自由发挥
  - 场景参考：到店餐饮、服务零售、酒店旅行、外卖、履约配送、闪购、医药健康……
