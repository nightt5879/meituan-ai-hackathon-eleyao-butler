## Step 1：注册 GitHub 账号

### 操作步骤

1. 打开浏览器，访问 **https://github.com**
2. 点右上角的 **"Sign up"**（注册）按钮
3. 依次填写：
   - **Email**：填你常用的邮箱（Gmail、QQ、163、学校邮箱都行）
   - **Password**：至少 15 位字符，或 8 位以上包含数字 + 小写字母
   - **Username**：⚠️ **重要，见下方说明**
4. 过一个人机验证（GitHub 的小游戏，跟着做就行）
5. GitHub 会给你邮箱发一个 **8 位验证码**，去邮箱复制粘贴回来
6. 进入引导页面时，问你"是个人还是团队"这类问题，随便选（选 free 免费版）
7. 看到自己的 GitHub 主页 = 注册成功 ✅

### 关于 Username（用户名）的建议

这个名字会公开显示，也会出现在你的所有代码链接里，**建议用英文**，注册后也不好改。

**推荐写法**：
- 拼音或英文名：`lileiwang`、`leonlee2026`
- 英文名 + 数字：`zhangsan-0423`
- 英文昵称

**不推荐**：
- ❌ 中文（github.com/张三 这种链接在海外访问会出问题）
- ❌ 很长的句子
- ❌ 带生日、身份证号等敏感信息

### 常见问题排查

| 问题 | 解决办法 |
|---|---|
| 收不到验证邮件 | 检查**垃圾邮件**文件夹；或者换个邮箱（Gmail 最稳） |
| Username 被占用 | 加个后缀数字或横线，比如 `yourname-2026` |
| 打开 github.com 很慢/打不开 | 换个时间段试试；或者切换网络（从 WiFi 切 4G/5G） |
| 密码一直提示太弱 | 用"一句英文 + 数字"组合，比如 `ILoveCoding2026` |

## Step 2：安装 GitHub Desktop

GitHub Desktop 是 GitHub 官方出的桌面客户端，你可以把它理解成"代码版的网盘"——我改的文件能同步给你，你改的能同步给我。

### 下载

1. 打开 **https://desktop.github.com**
2. 网页会自动识别你的电脑系统（Windows / Mac），点蓝色的大按钮下载
3. 下载完双击安装包，一路下一步

### 登录

1. 打开 GitHub Desktop
2. 看到欢迎页，点 **"Sign in to GitHub.com"**
3. 浏览器会自动弹出一个授权页面，点 **"Authorize desktop"**（授权）
4. 浏览器可能会提示"是否打开 GitHub Desktop"，选**是**
5. 回到 GitHub Desktop 能看到你的用户名，就算成功了 ✅

### 登录成功后的状态

登录成功后会让你"Clone a repository"（克隆仓库）。**这一步先不用操作**——等我把你加进项目仓库之后，这里会出现我们的仓库，你再 clone。
