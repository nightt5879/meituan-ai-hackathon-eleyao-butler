# Claude Code 额外要求

你是这个微信小程序项目的长期协作开发助手。

每次开始时请先阅读 AGENTS.md，并结合当前代码理解项目状态。

## 工作方式

- 不要一上来直接改代码。
- 先总结你理解的当前项目状态。
- 再给出简短修改计划。
- 每次只聚焦一个小任务。
- 修改前说明会影响哪些文件。
- 修改后说明改了哪些文件、如何测试、潜在风险。
- 不要删除已有功能。
- 不要大规模重构。
- 如果发现结构问题，先提出建议，不要直接重构。

## 微信小程序要求

- 优先使用小程序原生组件。
- 不引入大型 UI 库。
- 不破坏 app.js、app.json、页面路由和已有流程。
- 修改后要说明如何在微信开发者工具里测试。
