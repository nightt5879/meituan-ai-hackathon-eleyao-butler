\# 饿了幺 微信小程序前端 MVP



\## 1. 项目简介



「饿了幺」是一个 AI 本地生活决策助手的微信小程序前端 MVP。



当前阶段目标不是接入真实 AI、真实商家数据或复杂推荐算法，而是先跑通一个可演示的小闭环：



用户登录 → 进入首页 → 点击「今天吃什么」→ 通过问答收集偏好 → 展示 mock 店铺推荐 → 本地保存偏好记录 → 为后续接入 OpenClaw 预留接口。



\## 2. 当前阶段目标



本阶段重点完成：



\- 微信小程序基础页面结构

\- mock 登录态

\- 首页三个入口

\- 「今天吃什么」完整问答链路

\- mock AI 状态机

\- mock 店铺推荐

\- 本地偏好记忆

\- OpenClaw 接入点预留



当前不追求真实推荐质量，优先保证流程可跑通、状态可追踪、后续方便替换服务层。



\## 3. 如何运行项目



\### 3.1 环境要求



需要安装：



\- 微信开发者工具

\- Git

\- 可选：VS Code 或其他代码编辑器



\### 3.2 打开项目



1\. 打开微信开发者工具。

2\. 选择「导入项目」。

3\. 项目目录选择当前仓库下的小程序目录：



```text

<repo-root>\mini-program\wechat-miniprogram
```
